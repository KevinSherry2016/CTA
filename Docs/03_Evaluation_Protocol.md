# 因子评估与相关性分析标准 (Evaluation Protocol)

## 1. 自动化扫描收集
开发一个汇总性评估脚本 `Evaluate_All_Factors.py`，要求具备如下功能：
- 扫描 `./Result` 目录下所有的 `*BacktestResult.csv` 文件。

## 2. 稳健参数评估与表现汇总 (Robust Performance Matrix)
不再单纯提取“Max Sharpe”（容易陷入参数孤岛），而是必须执行以下两步校验来评估参数偏移/过拟合问题，选出最稳健参数：

### 2.1 稳健性检验维度：
1. **整体参数高原 (Parameter Plateau)**：
   - 观察回测整个期间内参数空间绩效分布的平滑性。
   - **单参数因子**：观察单一参数序列变化的绩效平滑曲线。
   - **多参数因子**（如 DualMA 的 `fast_n`, `slow_n`，或 MACD 的 `fast_n`, `slow_n`, `signal_n`）：需要在高维参数映射中观察平滑度，即在固定其他参数时，沿任意一个维度微调，其绩效都不应出现剧烈的衰落。最优参数组（如 `fast=12, slow=26` 等）的左、右、上、下相邻参数组合，其 Sharpe Ratio 应该处于相近的高水平带，而不应是孤岛或突兀的尖峰。
2. **年度盈亏一致性 (Annual Consistency)**：
   - 切分每年的日度收益率，计算该参数在按“年”度量时的 Sharpe Ratio。
   - 检验该参数是否每年都在整个参数簇中排名前列。排除那种只靠某单一年份（如2020年极端行情）产生暴利从而拉高整体均值的不稳定参数。

### 2.2 稳健性判定与输出表格：
综合1和2，研判所选的参数是否靠谱并存在向未来偏移的问题（Overfitting）。验证通过后，将这组“最靠谱参数”提列出来构建下方汇总表：

| Strategy/Factor Name | Robust Params | Plateau Verified | Annual Consistency | Sharpe @ Robust | POT @ Robust |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ... | ... | ... | ... | ... | ... |

- **指标说明**：
  - `Robust Params`: 经过参数高原和年度一致性双重检验后选出的最稳健参数组。
  - `Plateau Verified`: 该组合是否处于明显的宽阔参数高原 (Yes/No)。
  - `Annual Consistency`: 描述其稳健年份的占比或排名稳定性。
  - `POT`: 每万份换手净收益（代表滑点摩擦承受能力）。

### 2.3 模式效果对比 (Mode Comparison)
对于每一类因子（以及单一筛选出的稳健因子），都必须对其 `RAW` 模式和 `STATE_MACHINE` 模式的回测效果进行比较。
- 提取两种模式在最稳健参数下的核心绩效指标（仅比较 Sharpe Ratio 和 POT）并输出对比图表或者合并对比分析。
- 借此直观分析并总结连续预测强弱（RAW）与离散状态切分（STATE_MACHINE）在各分类（趋势、波动率、横截面等）下的普遍适用性倾向。

## 3. PnL 相关性矩阵 (PnL Correlation Matrix)
分析因子之间收益特征的同质性。我们关注的是策略盈亏（PnL）曲线的线性相关性。
- 对所有的策略产生的每日收益率序列（PnL）对齐到相同的时间索引。**注意：提取各因子的 PnL 数据时，必须统一使用其在第 2 步中所筛选出的最稳健参数（Robust Params / 参数高原）所对应的盈亏结果**。由于每个因子的输出有 `RAW` 和 `STATE_MACHINE` 两种模式，计算相关性矩阵时**必须将这两种模式分开**，分别进行评估。
- **划段计算**：必须分别计算两期相关性矩阵：
  1. **全样本（2010年至今）**：观察极其长期的宏观视角下的相关性。
  2. **中短期（2015年至今）**：重点观察近中期市场结构演变后的相关性。
- 计算不同阶段下，策略产生的每日收益率序列（或资金曲线）的 Pearson 相关系数矩阵。
- **分模式输出**：分别为 `RAW` 和 `STATE_MACHINE` 生成相关性矩阵。每种模式需包含：
  - 对称的策略收益相关性矩阵数据的 CSV 文件。
  - 易于直观观察的热力图（Heatmap）图像文件。

### 判定标准：
- **`corr > 0.8`**：高度同质化。该新因子几乎没有增量信息，信息冗余度高。
- **`0.4 < corr <= 0.8`**：中等相关。存在一定的共性特征。
- **`corr <= 0.4`**：正交因子。信息极具独立性，直接加入多策略组合（分配平行的独立权重资金）。

## 4. 下一步行动纲领
每完成一个新因子的开发与扫描，由 Agent 根据上述判定标准撰写一段综合分析，决定该因子在最终组合里的分配潜力和独立性。
